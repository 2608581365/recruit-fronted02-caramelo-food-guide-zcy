# 焦糖美食指南

## 项目简介
  “焦糖美食指南”是一个用于分享、搜索和管理美食信息的网站。
  它可以帮助用户记录餐馆、食堂、小吃和咖啡甜品，解决“今天吃什么”的选择困难。
  本项目主要使用：
- HTML：搭建页面结构
- CSS：完成页面布局和样式
- JavaScript：实现数据管理和页面交互
- localStorage：保存用户数据
# 主要功能
- 展示示例美食列表
- 使用关键词搜索美食
- 按美食类型筛选
- 按评分、价格和名称排序
- 收藏和取消收藏美食
- 新增美食信息
- 修改已有美食信息
- 删除美食信息
- 显示已收录数量、平均评分和收藏数量
- 随机推荐一条美食
- 数据保存到浏览器，刷新后仍然存在
- 对空输入和无搜索结果进行提示
- 适配电脑和手机屏幕
